# Architecture Decision Records

This directory records architecture decisions for the MolBlender `models/` module.

Each ADR is a short document capturing a decision that has lasting impact on the
codebase structure — a dependency direction, a type contract, or a boundary
rule.  New ADRs should follow the same format (context → decision → consequences).
